# 星禾科技 Singho · 开机动画模板

> 文件：`singho-boot-animation.html`（自包含单文件，浏览器打开即播）
> 叙事参考：「数字角色苏醒」类片头的四阶段结构；**素材 100% 为自有品牌资产，无任何第三方内容**

## 一、设计说明

| 阶段 | 时间 | 内容 |
|---|---|---|
| ① HUD 浮现 | 0–1.1s | 深空底 + 星空，四角括号、品牌名、状态词列表淡入，光轨划过 |
| ② 线稿自绘 | 1.1–3.0s | 猴头标三条真实 SVG 路径错峰勾勒：**外形 → 面部 → 双眼压轴** |
| ③ 上色绽放 | 3.0–4.7s | 渐变填充淡入 + 光晕绽放 + 品牌名「星禾科技」逐字点亮 |
| ④ 定格苏醒 | 4.7–7.2s | 口号浮现，**双眼眨动** + Logo 悬浮呼吸，状态词停在 READY |

叙事隐喻：勾形如播种（SEEDING）→ 面部如发芽（SPROUTING/GROWING）→ 双眼点亮如发光（GLOWING）→ 苏醒定格（READY），与「星禾 = 星辰 + 禾苗」的品牌意象对齐。

## 二、品牌资产来源（全部权威源）

| 资产 | 来源 |
|---|---|
| 猴头标线稿/填充 | `assets/星禾logo_猴头标.svg` 三条路径原样内嵌 |
| 配色 | 视觉规范 v1.0 token：紫 `#B41EEC` → 蓝 `#0E70F2` 渐变、深空底 `#06070F`、亮字 `#C77BFF`/`#6FA8FF`、暖点缀 `#FFB86B`（1 颗暖星） |
| 口号 | 「给众人送去希望和梦想」/「打造一家伟大的科技公司」（BaseLayout description，源自品牌文案） |
| 状态词 | SEEDING → SPROUTING → GROWING → GLOWING → POLISHING → READY |

## 三、自定义入口（HTML 内搜 `CUSTOM`）

1. **文案**：品牌名 `data-text`、口号、HUD 各文本块
2. **配色**：`:root` 的品牌 token（与视觉规范同步改）
3. **节奏**：JS `PHASES` 时刻与 `END` 总时长
4. **状态词**：可换成 BOOTING/RENDERING 等技术向词
