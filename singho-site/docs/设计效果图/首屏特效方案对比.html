首屏标题特效 · 六方案实时对比

以下六个都是真实运行的效果（非截图），参考自 GitHub 成熟方案，均适配品牌深空紫蓝体系 · E/F 为组合方案 · 选定后我再落地到 singho-site

方案 A柔光扫过 · Shimmer 参考：React Bits「ShinyText」/ Facebook Shimmer（CSS 经典）
星禾科技
一道柔光带每 5.5 秒从左到右扫过一次，其余时间保持安静。大厂官网最常用的"高级感"写法——克制、庄重、零性能负担，与品牌庄重感最兼容。备选：光带只在进入视口时扫一次。
方案 B极光渐变循环 · Gradient Flow 参考：React Bits「GradientText」/ theosoti animated-gradient
星禾科技
品牌紫→蓝渐变在文字内部像极光一样缓慢流动循环，没有突然的光带。文艺、静谧、高级；9 秒一轮几乎察觉不到起点终点。备选：叠加缓慢的辉光呼吸（更"活"一点）。
方案 C星尘粒子环绕 · Star Dust 参考：React Bits「Particles」/ tsParticles（自写 canvas，约 40 行）
星禾科技
40 颗品牌色星尘在文字周围缓慢漂浮、明灭，像星从字里长出来。科幻感最强、与首页星空背景浑然一体；也是与未来「星野凝字」粒子岛血缘最近的一版。粒子数/速度/亮度全部可调。
方案 D舞台光柱 · Light Rays 参考：React Bits「LightRays / Beams」思路（纯 CSS 实现）
星禾科技
三道柔和光柱从标题后方缓慢摆动，像舞台追光。氛围感、仪式感最强，标题本身保持完全安静；光柱是背景性的，不干扰文字。适合与 A 或 B 叠加成"组合拳"。
方案 EA+B 组合 · 极光渐变 + 柔光扫过 B 渐变流动作文字底色 + A 光带周期扫过（真实叠加态）
星禾科技
文字内部紫蓝渐变像极光一样缓慢流动（B 层），每隔几秒再有一道柔光带从左到右扫过、瞬间提亮（A 层）。流动负责"活"，扫光负责"惊艳一瞬"——两套周期错开，每个循环都不重样。层次最丰富的纯 CSS 方案，零性能负担，亮度比单 A 或单 B 略高（可调）。
方案 FA+B+D 组合 · 光柱舞台 + 极光 + 扫光 D 光柱铺背景 + B 渐变流动 + A 光带扫过（三层真实叠加）
星禾科技
方案 E 的全部效果 + 三道舞台光柱从标题后方缓缓摆动。整套首页的仪式感天花板：背景在动（光柱）、文字底色在动（极光）、高光在动（扫光），三层节奏互不干扰，"发布会开场"级气场。视觉信息量最大的一版；落地时会配套 prefers-reduced-motion 全量降级，移动端弱机自动削减光柱。

以上均可调节速度/亮度/颜色 · 组合推荐：追求稳重耐看选 E（A+B），追求全场气场选 F（A+B+D） · 选定后告知，落地约 30 分钟
