## 问题清单

### P-1 首页未按三件套参考图排版（比例失调）

| 项 | 内容 |
|---|---|
| 现象 | logo（猴头标）尺寸过大，"星禾科技"四个字过小，与参考图比例不符 |
| 参考基准 | `assets/星禾logo_三件套_深空底预览.png` + 视觉规范 P1 三件套 v5 规格 |
| 目标比例 | 猴头高 320 为基准：文字组整体 ≈ 猴头 93%；**中文主名 ≈ 猴头高 70%**（226/320）；Singho 眉题 ≈ 17%（56/320）；中文底边与猴头底边对齐，右列两行严格左对齐 |
| 涉及文件 | `src/components/home/BrandTrio.astro`（clamp 字号与 gap 需重调） |
| 优先级建议 | 高（品牌门面，访客 3 秒第一印象） |

### P-2 首页背景过于单调

| 项 | 内容 |
|---|---|
| 现象 | 仅静态星点层，缺乏纵深与氛围 |
| 优化方向 | 参考图同款「三件套后方品牌色氛围光晕」（紫→蓝径向渐变）+ 星野层次（近景/远景两层星点、可选低频漂移）；与「星野凝字」粒子动效岛的背景层一并设计，避免重复施工 |
| 涉及文件 | `src/components/home/BrandTrio.astro`（.starfield / 新增氛围光层）；后续与 `components/hero/` 粒子岛协同 |
| 优先级建议 | 中（与粒子动效岛合并处理，一次到位） |

### P-3 页面动画未能正常加载

| 项 | 内容 |
|---|---|
| 现象 | 启动封面 E0 / 口号屏 E15 依次点亮等动效未按预期播放 |
| 排查线索（待逐一排除） | ① `sessionStorage` 标记残留导致封面被跳过（之前访问已写入 `singho-intro-done`）；② Astro 组件内联 `<script>` 打包后的执行时序；③ `prefers-reduced-motion` 系统设置开启了"减少动画"，全局降级生效（属正常降级而非故障）；④ IntersectionObserver 阈值未达到（口号屏需 50% 可见） |
| 排查方法 | DevTools → Application → Session Storage 清标记复现；Console 看脚本是否执行；检查系统"减少动画"设置 |
| 优先级建议 | 中（先确认是 bug 还是降级正常生效，再定级） |
